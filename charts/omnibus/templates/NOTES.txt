WARNING: OMNIBUS_PUBLIC_ORIGIN is not set (no ingress host, no `publicOrigin`).
The CSRF gate falls back to comparing against the Host header, which breaks
behind any proxy that rewrites Host: reads work, every write returns 403.
If you reach Omnibus at a fixed URL, set it:

{{- if .Values.config.trustForwardedFor }}

WARNING: config.trustForwardedFor is on. Only safe when every request reaches
the pod through a proxy that overwrites X-Forwarded-For. If the Service is
reachable directly (NodePort/LoadBalancer, or a NetworkPolicy-free cluster),
a client can spoof the header and walk past the login rate limit.
